# ADR-006: Latency-классы агентов

## Статус
Accepted

## Контекст
Использование одной модели для всех задач:
- GigaChat 3.5 Ultra (432B MoE) избыточен для чат-бота.
- Экономически неэффективно.

## Решение
Разделение на два класса:
- Фоновый: GigaChat 3.5 Ultra, 15 мин, 1.0 CU, 200k tokens.
- Интерактивный: GigaChat 3 Lightning, 5 сек, 0.02 CU, 5k tokens.

Правило: интерактивный агент не может использовать модель фонового.

## Последствия
Плюсы:
- Экономия CU.
- Низкая latency для чат-бота.
- Правильная утилизация GPU.

Минусы:
- Два разных пайплайна.
- Сложность fallback-логики.
