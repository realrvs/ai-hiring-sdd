# ADR-008: Политика визуальных артефактов в SDD

**Статус:** Принято
**Дата:** 2026-10-07
**Контекст:** Заказчики (C-Level, HRD, DPO) требуют диаграммы и макеты для утверждения Proposal и Specs.

## Решение

1. **Диаграммы** — только в формате Mermaid, встраиваются в `docs/design/DES-*.md`. Причина: версионируемость, генерация AI-агентом, читаемость в GitHub.
2. **Макеты** — собираются через воркфлоу `/opsx:design` (или аналог). Результат: `docs/design/DESIGN-BRIEF-*.md` + `assets/`.
3. **Правило изоляции:** во время сбора макетов агент НЕ редактирует код. Только `DESIGN-BRIEF` и `assets/`.
4. **Утверждение:** DESIGN-BRIEF согласуется с HRD/DPO **до** перехода к `api-contract`.

## Последствия

- (+) Единый источник правды для визуальных требований.
- (+) AI-агент получает контекст структуры UI до генерации кода.
- (−) Требуется MCP-интеграция с Figma или ручной экспорт скриншотов.
