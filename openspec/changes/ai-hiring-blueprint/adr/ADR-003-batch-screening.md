# ADR-003: Batch Screening как default для фоновых агентов

## Статус
Accepted

## Контекст
Обработка резюме по одному:
- 10 резюме = 10 CU.
- Дорого, медленно.

## Решение
Batch Screening:
- Default: 5-10 резюме на один системный промпт.
- Исключения: метка no-batch (C-level, уникальные роли).
- Экономия до 90% CU.

## Последствия
Плюсы:
- 1.0 CU вместо 10.0 CU.
- Экономия до 90%.
- Cost per Hire снижается в 6.4x.

Минусы:
- Риск "усреднения" оценок внутри батча.
- Требуется тщательный выбор batch size.
