# ADR-007: Compute Units как универсальная метрика

## Статус
Accepted

## Контекст
Разные модели, разные тарифы, разные единицы измерения:
- Токены, GPU-часы, рубли.

## Решение
Compute Units:
- 1 CU = 1 GPU-час на RTX PRO 6000.
- 1M токенов GigaChat Max = 0.65 CU.
- CU_TO_RUB = 1000 руб (on-prem) или 650 руб (API).

## Последствия
Плюсы:
- Единая метрика для on-prem и API.
- Прозрачный Cost per Hire.
- Сравнение эффективности.

Минусы:
- Требуется калибровка.
- Может устаревать при смене железа.
