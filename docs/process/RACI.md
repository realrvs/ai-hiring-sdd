# RACI Matrix - AI Hiring SDD

## Легенда
- **A** - Accountable (один на этап, отвечает за результат)
- **R** - Responsible (выполняет работу)
- **C** - Consulted (даёт вход, обязательное ревью)
- **I** - Informed (уведомляется)

## Правила

1. **Один Accountable на этап.** Если их два - это баг процесса.
2. **Accountable не может делегировать merge.** Только он нажимает кнопку.
3. **Consulted обязан дать ревью** в течение 24 часов (SLA).
4. **Informed не блокирует** merge, но получает уведомление.
5. **DPO / Compliance** - обязательный Consulted для всего, что касается PII (Specs, Design, API, Apply).

## Роль Process Owner

**Ответственность:**
- Актуализация CODEOWNERS, шаблонов PR, меток.
- Проведение ретро раз в квартал.
- Эскалация нарушений процесса.
- Ведение метрик процесса.

**Не ответственен за:**
- Содержание артефактов.
- Технические решения.
- Бизнес-приоритеты.
