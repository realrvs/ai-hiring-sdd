## 1. Компонентная архитектура

### 1.1. Слои (сверху вниз)

```mermaid
flowchart TB
    A["HR LLM GATEWAY<br/>(KodikRouter / LiteLLM, on-prem)<br/>Two-Way Masking | 152-ФЗ | Rate Limiting | Budget"]
    B["RECRUITMENT AGENT PLATFORM<br/>Docker-песочницы | ATS/HRIS API | Circuit Breaker"]
    C["CANDIDATE CONTEXT PROVIDER<br/>(MCP-сервер)<br/>Резюме | Портфолио | Feedback | context-gap"]
    D["ARTIFACT STORE<br/>(Gitea / GitLab On-premise)<br/>JD | Scorecards | Interview Kits | Audit Trail"]
    E["CONSENT & RETENTION LAYER<br/>TTL-менеджер | Purge Pipeline | Audit Vault"]
    F["ANONYMIZATION TOKENIZER<br/>PII → Token | Token Vault (AES-256)"]

    A --> B --> C --> D --> E --> F
```

### 1.2. Latency-классы агентов

| Параметр | Фоновый | Интерактивный |
|---|---|---|
| Задачи | Скрининг, ранжирование, JD | Чат-бот, FAQ, scheduling |
| Latency p95 | 15 мин | 5 сек |
| Модель | GigaChat 3.5 Ultra | GigaChat 3 Lightning |
| Бюджет | 1.0 CU / батч | 0.02 CU |
| Max tokens | 200k | 5k |
| Fallback | Ур. 2 → Ур. 3 | Lite → кэш → человек |

Правило: интерактивный агент не может использовать модель фонового.

## 3. Технологический стек

| Слой | Технология |
|---|---|
| LLM (фон) | GigaChat 3.5 Ultra (on-prem, 432B MoE) |
| LLM (интерактив) | GigaChat 3 Lightning (Edge/API) |
| LLM (локальный) | Qwen / DeepSeek через Ollama |
| Gateway | KodikRouter / LiteLLM |
| Artifact Store | Gitea / GitLab On-premise |
| CI/CD | Gitea Actions |
| PII Scan | Semgrep (режим Block) |
| Token Vault | On-prem, AES-256 |
| Vector DB | RAG-индекс (3 мес TTL) |
| MCP | MCP-сервер для Gitea/Forgejo |
| Контейнеризация | Docker (изолированные песочницы) |

## 4. Диаграмма состояний вакансии

```mermaid
stateDiagram-v2

    Intake --> Sourcing
    Sourcing --> Screening
    Screening --> Interview

    Offer --> Hired

    Intake --> Reject
    Sourcing --> Reopen
    Screening --> Feedback
    Interview --> Escalation
    Offer --> Hired

    Reject --> ConsentRevoked
    Reopen --> ConsentRevoked
    Feedback --> ConsentRevoked
    Escalation --> ConsentRevoked
    Hired --> ConsentRevoked

    ConsentRevoked --> Purge
    Purge --> [*]
```
