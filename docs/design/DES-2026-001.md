### 1.2. Latency-классы агентов

| Параметр | Фоновый | Интерактивный |
|---|---|---|
| Задачи | Скрининг, ранжирование, JD | Чат-бот, FAQ, scheduling |
| Latency p95 | 15 мин | 5 сек |
| Модель | GigaChat 3.5 Ultra | GigaChat 3 Lightning |
| Бюджет | 1.0 CU / батч | 0.02 CU |
| Max tokens | 200k | 5k |
| Fallback | Ур. 2 -> Ур. 3 | Lite -> кэш -> человек |

Правило: интерактивный агент не может использовать модель фонового.

## 2. Потоки данных

### 2.1. Screening (batch)

~~~text
Резюме (PII) -> Pre-commit hook PII-детектор
-> Gitea Actions (Semgrep PII, Block)
-> Anonymization Tokenizer (PII -> Token)
-> LLM Gateway (работает с токенами)
-> GigaChat 3 Lightning (batch 5-10)
-> Scorecard + риски
-> Re-identification в UI рекрутера (RBAC)
-> Self-Check Report
~~~

### 2.2. Consent Revocation (hard trigger)

~~~text
Кандидат отзывает согласие (API/UI/email)
-> Consent API (мгновенно)
-> Метка consent-revoked (Gitea Actions, <5 мин)
-> Circuit Breaker: остановка всех пайплайнов
-> Purge Pipeline (<1 час):
   - Git: force-push + git filter-repo (<2 ч)
   - Vector Index: полное удаление (<2 ч)
   - MCP Logs: PII redaction (<4 ч)
-> Audit Vault: запись "Purge выполнен" (<4 ч)
~~~
