# UX Components

## TokenBadge
Визуальная индикация маскированных данных.

Состояния:
- masked - серый бейдж "Данные маскированы"
- revealed - жёлтый бейдж "PII раскрыты"
- audit - синий бейдж "Демаскирование залогировано"

Поведение:
- При клике "Показать PII" -> reveal + запись в Audit Vault.
- При смене роли -> автоматический возврат в masked.
- Доступен только роли recruiter.

## ConsentStatus
Статус согласия кандидата.

Состояния:
- active - зелёный
- expiring - жёлтый (TTL < 30 дней)
- revoked - красный

## BudgetMeter
Оставшийся CU агента.

Состояния:
- ok - зелёный
- warning - жёлтый (> 80% использовано)
- exceeded - красный (остановка)

## AuditLog
История демаскирований.

Поля:
- кто (recruiter_id)
- когда (timestamp)
- какой токен (token_id)
- audit_id
