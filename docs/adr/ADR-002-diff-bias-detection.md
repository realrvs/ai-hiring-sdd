# ADR-002: Diff-based Bias Detection вместо полного сканирования

## Статус
Accepted

## Контекст
Полное сканирование всех решений на bias:
- Блокирует процесс.
- Требует огромных ресурсов.
- Дает много ложных срабатываний.

## Решение
Diff-based Bias Detection:
- Запуск асинхронно после каждого этапа.
- Только измененные решения (по diff).
- Fairness score для измененных + накопленный по репозиторию.
- Пороги: измененные <85% -> bias-risk; накопленный <80% -> tech-debt:bias-audit.

## Последствия
Плюсы:
- Не блокирует процесс.
- Точная картина fairness для новых решений.
- Предотвращает незаметную деградацию.

Минусы:
- Требует внешнего аудита.
- Накопленный score может запаздывать.
