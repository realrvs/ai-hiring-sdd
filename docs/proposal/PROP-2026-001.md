## 1. Проблема
Корпоративный найм в enterprise-контуре сталкивается с:
- Высоким Cost per Hire (40 ч x 3000 руб = 120 000 руб на вакансию).
- Длинным Time-to-Hire (3+ недели).
- Рисками утечки PII (152-ФЗ, GDPR Art. 17).
- Неконтролируемым использованием LLM (галлюцинации, дискриминация).
- Отсутствием метрик качества найма (fairness, bias, latency).

## 2. Предлагаемое решение
Создать Blueprint - корпоративный стандарт автоматизации найма через три фазы зрелости:
- Фаза 1: Assist - AI помогает, человек решает (Human-in-the-Loop).
- Фаза 2: Augment - AI ведет процесс, человек валидирует (Human-on-the-Loop).
- Фаза 3: Autonomous - AI закрывает вакансию, человек - финальный оффер.

## 3. Ключевые компоненты
| Компонент | Назначение |
|---|---|
| HR LLM Gateway | Two-Way Masking, 152-ФЗ, budget enforcement |
| Recruitment Agent Platform | Изолированные песочницы, ATS/HRIS API |
| Candidate Context Provider (MCP) | Инкрементальное обогащение контекста |
| Artifact Store (Gitea) | Docs-as-Code, CI/CD, PII Scan |
| Consent & Retention Layer | TTL, Purge Pipeline, Right to be Forgotten |
| Anonymization Tokenizer | PII -> Token, Token Vault (AES-256) |

## 4. Ожидаемые результаты
| Метрика | Baseline | Цель |
|---|---|---|
| Time-to-Hire | 21 день | 12-14 дней (-30-40%) |
| Cost per Hire | 120 000 руб | < 84 000 руб (< 0.7x) |
| Fairness score | - | > 85% |
| PII-инциденты | - | 0 критических |
| Purge SLA | - | < 4 часа |
| Batch screening rate | 0% | > 80% |

## 5. Ограничения и риски
- Импортозамещение: on-prem GigaChat 3.5 Ultra (432B MoE) требует GPU-кластера.
- 152-ФЗ: обязательна Token Vault on-prem, RBAC на re-identification.
- Не прыгать фазы: Фаза 1 -> Фаза 3 запрещен. Минимум 2 квартала на фазу.
- Риск галлюцинаций: Self-Check Report обязателен на каждом этапе.
- Риск bias: Diff-based Bias Detection асинхронно после каждого этапа.

## 6. Альтернативы (отклонены)
| Альтернатива | Почему отклонена |
|---|---|
| Покупка готового ATS с AI | Нет контроля над PII, нет on-prem |
| Классическое NER-маскирование | Необратимо, теряет смысл контекста |
| Полная автономия сразу (Фаза 3) | Нарушает правило перехода, высокий риск |
